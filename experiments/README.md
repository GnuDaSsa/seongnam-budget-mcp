## Follow-up: evaluation, original sources, and compact response

The fixed `evaluate.mjs` set contains seven predeclared checks: 2026 total, youth rent, performance-plan intent, research-center revision, the 2007 XLS row, an out-of-vocabulary query, and a two-year query. The latter five mostly reuse existing regression expectations; this small, non-independent convenience set is not an estimate of corpus-wide precision, recall, or answer correctness. Five fresh Node processes per version ran the set in the same sequence, with five repeats after each first query. All 7 checks passed in all five base and modified runs. The first query per case is not uniformly cold: assets and VM state may already have been warmed by earlier cases. Raw data: `evaluation-base-repeated.jsonl`, `evaluation-after-repeated.jsonl`.

These are local in-process synthetic timings; no claim of production latency improvement or statistical significance.

With the new opt-in `response_format: compact`, multi-year `per_year[].evidence_ids` references the unchanged complete top-level evidence. For the fixed comparison, full modified JSON-RPC response was 131,638 bytes and compact was 80,078 bytes, a 39.2% reduction. All five runs reconstructed each year's evidence exactly. The default `full` structure remains compatible, and MCP text plus structured content are both kept. This result is one example, not a general payload distribution.
