# Cycle 4 — cache, concurrency and natural questions

Base is the previous local patch on deployed Sites source c5d4d14; all tests use immutable, hash-verified local snapshot files and never contact production. `test-cycle4-final3.log`: 65/65 tests. Three paired fresh Node v25 processes per benchmark; local file-backed synthetic ASSETS, not Cloudflare Workers or user/GPT wall time. Each first-call comparison is a small sample; no statistical confidence or p95 is claimed.

## Cache correctness and concurrency

`EvidenceCache` accounts for twice the UTF-16 lengths of key and serialized value plus 256 bytes per entry, with a 1,000,000-byte estimated budget, maximum 64 entries, and five-minute TTL. This is accounting, not a hard JS heap or RSS limit. Tests use a fake clock to verify expiry at the boundary, access isolation, replacement, expired-entry removal on access/insertion, LRU, Unicode, oversized keys and 10,000 insertions. Expired entries are not actively swept while idle, but bounded accounting remains in force. Snapshot catalog hash is included in keys; cached evidence assumes assets are immutable within a deployment. User query is present only in bounded per-isolate in-memory keys, with no persistent question logging. Other pre-existing caches and pending work are separate from this budget.

For identical in-flight work, search and evidence loads are coalesced only when asset binding, operation and input key match. The map is limited to 64 in-flight entries per binding; different requests beyond that are not limited. Tests verify duplicate sharing, caller result cloning, rejection then retry, separate keys/kinds/bindings, and limit behavior. No guarantee is made for a never-settling upstream request; entries are removed when its promise settles.

Three processes, eight identical simultaneous cold calls: baseline median 1,108.53ms, 373 asset reads, peak local RSS 566,512 KiB; final median 253.01ms, 51 reads, peak RSS 240,000 KiB. All eight results had identical evidence, no errors. These are macOS Node peak process RSS numbers, not Workers heap; they exceed 128MiB and do not demonstrate production memory safety. Warm batches each had zero reads. Four different simultaneous queries cannot coalesce: baseline median 535.26ms/177 reads/321,632KiB peak RSS, final 524.61ms/178 reads/325,856KiB. Requested years, types and reported unit labels matched between runs, including `원문 확인`; no assertion was made that all returned hits were relevant or every number used the page unit. Different-query concurrency and production memory remain unresolved. Raw files: `concurrency-before.jsonl`, `concurrency-final3.jsonl`, `mixed-before.jsonl`, `mixed-final.jsonl`.

## Natural language, years, type, and unit

- A query with an explicit year and a conflicting year argument or all-year scope formerly returned the argument's year/all years silently. It now returns a clear error. An explicit multi-year comparison plus a single `year` parameter also asks the caller to omit that parameter. Internal per-year calls continue to work. Embedded model-like identifiers such as `AI2025X` no longer set the year. Existing fixed default 2026 remains unchanged.
- `2025년 본예산과 결산 청년월세 비교`, limit 2: baseline returned 본예산 and unrequested 추경, no 결산. Final separately searches requested 본예산 and 결산 (one kind at a time), returns per-kind candidates, marks missing kinds and unverified comparability, and excludes unrequested 추경. It cannot prove identity, compare columns or calculate differences. It supports at most two kinds per request. Three runs: baseline median 276.74ms, 60 reads, 43,645 bytes; final 262.74ms, 75 reads, 97,716 bytes. The payload increased because it returns both requested groups and their evidence; optional compact response can reduce duplication, not applied in these measurements. Raw `natural-before.jsonl`, `natural-final.jsonl`.
- Unit is an extracted marker somewhere in the source page, not universally valid for every value. Results now include `unit_scope` and server instructions requiring a value's explicit unit and the header's scope to be checked. Official settlement PDF https://www.seongnam.go.kr/bbs030503/getFile?bbsCrtSn=17012&pstSn=405828&fileNo=3, PDF page 417, catalog-matching SHA-256 `dc920d9c057559c3e6398ccda6c4e06873d349d31dbe682a61d9ac900949dcbe`: the narrative says 2,735백만원 while the lower table says 단위 원. This page was visually inspected using PDFKit; `work/pdf/` is ignored.
- `cycle4-final-base.jsonl` and `cycle4-final-after.jsonl`: the earlier 16 fixed presence/filter conditions passed 16/16 in all three paired runs. Core evidence hash was unchanged in all 16 when the newly added `unit_scope` field was omitted for comparison. This does not verify all-hit precision, every quantity, or corpus-wide correctness.

## Remaining

Production Worker memory, concurrency for distinct requests, load, tail latency, slow or never-settling assets and deployment cannot be inferred from this local test. The result cache and coalescing improve identical traffic but do not impose global concurrency limits. Full-response duplicate evidence and cache-key memory remain bounded only as documented. The fixed query set is not blinded or representative. Sites and GitHub have separate histories/asset policies; no PR, merge, deployment or production mutation was attempted.
