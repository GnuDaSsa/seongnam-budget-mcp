# 의회 예산 설명 근거

## 수록 범위

의회 자료는 성남시 세출예산사업명세서를 보충하는 설명 근거다. 시 명세서의 금액과 분류를 먼저 제시하고, 의회 제출안 설명을 별도 출처로 표시한다. 제출안·의결 예산·집행액을 같은 값으로 취급하거나 합산하지 않는다.

2026년 본예산 중 중원구보건소 건강증진과의 다음 세 사업에 대해 확인한 회의록 발언 구간을 색인한다.

| 시 명세서 사업 | 의회 발언에서 언급한 설명자료 쪽 | 확인 범위 |
|---|---|---|
| 산모신생아건강관리지원사업(전환사업) | 67 | 의회에서는 전환형으로 표현. 총액·증액 대조 |
| 암환자의료비및재가암관리지원(암환자의료비지원)(전환사업) | 78 | 증감액 대조. 해당 발언에는 총액 없음 |
| 성남시민건강박람회추진 | 88 | 총액·신규 편성 설명 대조 |

출처는 [성남시의회](https://www.sncouncil.go.kr/)의 제307회 문화복지체육위원회 제5차 회의록(2025년 12월 8일)이다. 개별 회의록·첨부의 공식 URL은 체크섬으로 검증하는 데이터 스냅샷에 원형 그대로 보존하고, MCP 검색 결과의 `source_url`로 반환한다. 회의 개최일과 예산연도는 다르다.

67·78·88은 발언자가 언급한 설명자료 쪽수이며, 확보한 첨부 PDF의 물리 쪽수가 아니다. MCP의 조회 위치는 수록한 텍스트 구간이다. `get_budget_page`에 반환된 문서 ID와 위치를 그대로 사용한다.

## 확보 현황과 제외

- 제307회 문화복지체육위원회 3·5차, 행정교육위원회 3차, 도시건설위원회 3·5차, 경제환경위원회 6차 회의록을 조사했다.
- 관련부록 48건은 제목·소관·공식 주소와 회의 안건 근거를 확보했다. 2026 본예산안 31건, 2026 기금운용계획안 5건, 2025 제4회 추경 10건, 의사일정 변경안 2건이다.
- 첨부 내려받기 경로는 공식 robots.txt의 자동수집 제한 대상이다. 첨부 본문은 확보하지 않았고, 목록을 본문처럼 임베딩하거나 검색 근거로 사용하지 않는다.
- 여섯 회의 전체를 한 예산연도·기관으로 색인하지 않는다. 회의에는 여러 연도·회차와 기관 자체 예산이 혼재한다. 이번 검색 범위는 위 세 발언 구간이다.
- 문서 자체 텍스트만 사용하며 OCR은 사용하지 않는다. 의회 전체 예산 설명자료를 수록한 것으로 표현하지 않는다.

## 사업 연결

연도, 예산종류, 회차, 기관, 회계, 부서, 사업명과 사업 계층을 확인한다. 원문에 없는 의회 쪽 회계·편성목·통계목은 시 자료에서 복사해 채우지 않는다. 공백과 유니코드 표현만 정규화하고, 전환형·추가형 같은 의미 있는 차이는 삭제하지 않는다. 검토된 별칭도 해당 연도·부서·사업에 한정한다.

전체본과 부서별 PDF는 물리 쪽수가 달라질 수 있다. 문서 ID·페이지 일치만으로 사업을 연결하지 않으며, 한 페이지에 함께 실린 다른 사업을 연결하지 않는다. 금액의 동일 여부와 사업의 동일 여부를 분리한다. 시 출연금과 기관 자체 예산도 분리한다.

원문을 추가 확보하면 내장 텍스트와 해시, 안건·사업 범위, 정오표 및 심사 변경을 확인한 뒤 색인한다. 미확인 값은 null이며, 검색 실패나 원문 미확보를 예산 0원으로 해석하지 않는다.

## 검색과 운영

기존 성남시 벡터 색인은 유지하고, 의회 구간은 같은 Potion 256차원 인코더로 만든 별도 검색 자산으로 관리한다. 검색 시 연도·예산종류·회차·기관 범위를 적용하며 기존 성남시 자료를 우선한다. 산하기관 자료는 기존의 명시적 기관 요청 규칙을 유지한다.

의회 보충 근거도 MCP에 수록된 텍스트에서 반환한다. 사용자가 명시적으로 웹 보충을 요청하지 않은 경우 외부 웹 검색으로 설명자료를 대신 찾지 않는다. 연결 주소와 도구 이름은 유지한다.
