# 명시 부서와 예산 편성 구분

부서명을 명시한 질문은 수록 원문의 `부서:` 머리말로 확인한 범위에서 검색한다. 공백과 영문 대소문자 차이는 정규화하되 다른 부서를 동의어로 자동 치환하지 않는다. 의미 유사도가 높아도 다른 부서의 금액을 해당 부서 예산으로 반환하지 않는다.

명시한 본예산·추경·결산·회차는 유지한다. 해당 편성에서 부서 원문이 확인되지 않으면 근거 없음으로 응답하고, 같은 연도·같은 부서의 다른 수록 편성이 확인된 경우 그 목록만 별도 안내한다. 추경 금액을 본예산 금액으로 자동 대체하거나 원문 미확인을 0원으로 해석하지 않는다.

예산 종류와 회차를 따로 명시하지 않은 `최신 예산`·`최종 예산`은 수록된 최종 추경을 찾는 요청으로 처리한다. 이는 외부 사이트의 최신 게시물을 실시간 확인했다는 뜻이 아니다. 명시한 본예산·결산 조건이 있으면 그 조건을 우선한다.

## 2025년 AI반도체과 사례

- 일반적인 `AI반도체과 2025년도 예산` 질문은 원래도 2·3·4회 추경을 찾을 수 있었다. 검색 실패를 코퍼스 전체 누락으로 판단하지 않는다.
- 2025년 본예산의 수록 원문에는 `AI반도체과` 머리말이 확인되지 않는다. [4차산업추진단 본예산, PDF 3~4쪽](https://www.seongnam.go.kr/humanframe/file/sncity/bgt/2025/11599_3_9.pdf#page=3)에는 미래산업과 소관 반도체 관련 개별 사업이 있다. 미래산업과 전체 예산을 AI반도체과 예산으로 자동 승계하지 않는다.
- [제2회 추경 PDF 21~22쪽](https://www.seongnam.go.kr/humanframe/file/sncity/bgt/2025/11604_2_3.pdf#page=21), [제3회 추경 PDF 37쪽](https://www.seongnam.go.kr/humanframe/file/sncity/bgt/2025/11604_3_3.pdf#page=37), [제4회 추경 PDF 9쪽](https://www.seongnam.go.kr/humanframe/file/sncity/bgt/2025/11604_4_3.pdf#page=9)에 AI반도체과 머리말이 확인된다.
- 본예산으로 한정했을 때 도시계획과·예산과 등 무관한 결과가 반환되거나, `최종 예산`에 결산 자료가 반환되던 경우를 회귀 검사한다.
- 영문으로 시작하는 사업명도 사업 경계로 처리한다. `AI 인재양성지원사업`의 편성목이 앞 사업에 붙지 않게 하며, 구조가 불명확하면 분류를 미확인으로 남긴다.

부서 검색용 보조 색인은 기존 추출 텍스트에서 생성한다. 원문과 기존 임베딩을 재작성하지 않으며, OCR이나 새 외부 자료 보충을 수행하지 않는다.
