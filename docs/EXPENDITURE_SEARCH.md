# 세출예산 근거 우선 조회

일반 사업비·편성목·통계목 질문은 세출예산의 해당 사업 내역을 우선 조회합니다. 성과계획서의 요약 금액으로 통계목이나 산출기초를 대신 설명하지 않습니다.

- 문서 종류와 편성 구분은 별개입니다. 카탈로그의 `budget_type=본예산` 안에도 성과계획서가 있으므로 문서 제목·분류를 함께 구별합니다.
- 성과계획·성과목표·성과지표를 명시하면 해당 자료를 조회합니다. 세입·결산·추경 회차와 사용자가 지정한 필터도 유지합니다.
- 일반 질문을 일괄적으로 본예산으로 제한하지 않습니다. 추경에서만 확인되는 사업은 추경 회차를 밝혀 제시하고, 본예산 금액으로 바꾸어 설명하지 않습니다.
- 사업명과 `통계목 보여줘` 같은 출력 요청을 구분합니다. 여러 검색 단어가 실제 원문 가까이에 함께 있는지 확인하며, 원문의 사업명을 임의 동의어로 바꾸지 않습니다.

사업별 설명은 확인된 범위에서 다음 항목을 보여줍니다.

| 항목 | 표시 기준 |
|---|---|
| 적용 기준 | 회계연도, 본예산·추경 회차·결산, 회계 |
| 사업 경로 | 담당 부서 → 정책사업 → 단위사업 → 세부사업 |
| 목 코드 | 편성목 코드·명칭, 통계목 코드·명칭 |
| 금액 | 원문 행과 열 제목, 원문 단위, 필요하면 명시한 환산값 |
| 출처 | 문서명, PDF 쪽수 또는 본문 위치, 공식 원문 링크 |

같은 페이지의 다른 사업 경로를 질문의 사업에 붙이지 않습니다. 이전 페이지에만 있는 상위 사업이나 불명확한 금액 열은 추정하지 않습니다. 분류 경로가 확인되었다고 자동 합계나 표 전체의 검산까지 끝났다는 뜻은 아닙니다.

실제 회귀 사례는 청년월세지원사업의 세출명세서/성과계획서 구별, 판교 연구센터의 2026년 1회 추경 근거, 2025년 자본적위탁사업비의 원문 통계목 확인입니다. 검증 결과는 변경 시점의 테스트 및 배포 기록과 함께 확인합니다.
