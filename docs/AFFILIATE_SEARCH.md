# 산하기관 공개자료 검색 범위

기본 검색은 성남시청 공개 예산자료만 사용한다. 질문에서 산하기관 포함을 명시하거나 기관명을 지정한 경우에만 수록된 기관 자체 자료를 함께 조회한다. 시 자료를 먼저 반환하며 기관 근거가 있으면 결과 일부를 기관 자료에 배정한다. 직전 질문의 범위를 다음 질문에 자동으로 이어 붙이지 않는다.

- `청소년 예산` → 성남시 자료만
- `산하기관도 포함해서 청소년 예산` → 시 자료와 수록된 기관 자료
- `성남시청소년청년재단 예산` → 시 자료와 해당 기관 자료
- `출연기관 제외하고 청소년 예산` → 시 자료만
- `시청 예산서에 있는 문화재단 출연금만` → 시 자료만

시청 코퍼스와 기존 벡터는 그대로 유지한다. 기관 자료는 `snapshot/affiliates/catalog.json`에 출처·기관·연도·자료 종류·상세 수준을 기록하고, 문서별 gzip 파일을 별도 키워드 검색한다. 기관 자료를 벡터화했다고 표시하지 않는다. 페이지 본문은 기본 검색에서 읽지 않는다.

빌드는 각 기관 파일의 바이트 수와 SHA-256을 카탈로그 및 `snapshot/assets.json`에 대조한다. 본문 파일은 소스 저장소에서 제외하며 기존 스냅샷 복원 도구가 검증해 내려받는다. 공개 전의 새 파일은 검증된 로컬 스냅샷에서 Sites checkout으로 별도 복사하고 빌드 검증을 거쳐야 한다.

모든 근거에는 `source_scope`, `institution_id`, `institution_name`을 표시한다. 기관 자료에는 `detail_level`, `document_stage`도 표시한다. 총괄표는 세부 예산서가 아니며 `proposal`은 예산안으로 설명한다. 시 출연금·위탁비와 기관 수입·지출을 합산하면 중복될 수 있으므로 기관 간 합계는 자동 계산하지 않는다. 최신 추경은 기관마다 수록된 최종 회차를 사용한다.

수집되지 않은 기관, 실패·미지원 원문, 총괄표만 수록한 경우는 수집 현황에서 구분한다. 검색 결과가 없다는 사실을 예산 0원 또는 사업 부재로 해석하지 않는다.
