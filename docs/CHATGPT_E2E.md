# 일반 ChatGPT 검증

2026-11-08에 ChatGPT 웹의 Chat 모드(Pro)에 인증 없는 `/public-mcp`를 연결했다. API 시뮬레이션이 아니라 실제 UI 대화다.

| 질문 | 확인 | 결과 |
|---|---|---|
| 2026년 본예산 총규모·일반/특별회계 | 3,940,847,350천원, 3,364,121,953천원, 576,725,397천원. 공식 PDF 1·2쪽 | 통과 |
| 2026년 청년 월세·보증금 이자 | 본예산 4,020,578천원과 성과계획 4,021백만원을 구분. PDF 345·636쪽 | 통과 |
| 2007년 도서관 | 4,000천원. XLS 본청 및 사업소 I2/I5125/J5125. PDF 쪽수를 생성하지 않음 | 통과 |

화면에 표시된 처리 시간은 각각 1분 37초, 1분 35초, 1분 2초였다. 이는 GPT의 사고·도구 선택·응답 작성을 포함한 시간으로 MCP 검색 지연과 다르다. 출처 표를 직접 렌더링하고 XLS 셀을 읽어 대조했다. 사용자 대화 URL·화면은 공개 레포에 포함하지 않는다.

## 2026-11-09 정책 개정 후 확인

공개 운영 버전 8(서버 0.3.0)을 배포하고 기존 무인증 MCP의 도구를 새로 고친 뒤 새 ChatGPT 대화에서 확인했다. 연도나 분류 항목을 요구하는 문구를 질문에 덧붙이지 않았다.

| 실제 입력 | 관찰한 응답 | 결과 |
|---|---|---|
| 성남시 예산 얼마야? | 첫머리에 2026년 본예산 기준을 명시. 총액 3,940,847,350천원, 일반회계 3,364,121,953천원, 특별회계 576,725,397천원. 공식 PDF 1쪽 링크 | 통과 |
| 청년월세 지원 예산은 얼마야? | 4,020,578천원. 국비 2,010,289·도비 603,087·시비 1,407,202천원을 구분. 예산 편성 경로를 자동 표시하고 공식 PDF 345쪽 링크 | 통과 |

두 번째 응답에는 **청년청소년과 → 청년복지증진 → 청년생활안정지원 → 청년월세지원사업 → 301 일반보전금 → 01 사회보장적수혜금(국고보조재원)**이 표시됐다. 같은 페이지 상단의 다른 단위사업인 청년역량지원으로 잘못 연결하지 않았다. [원문 PDF 345쪽](https://www.seongnam.go.kr/humanframe/file/sncity/bgt/2026/11608_3.pdf#page=345)의 금액·분류와 대조했다.

화면의 전체 처리 시간은 각각 50초와 39초였다. 같은 시점 익명 MCP 직접 호출 표본은 총예산 1,920ms, 청년월세 5,224ms였으며 초기화와 네트워크 조건이 다른 별도 표본이다. 부하 테스트나 지연 보장이 아니다. GPT의 지침 준수는 모든 질문에 대해 보장되지 않으며 미지원 표 서식은 분류를 확인 불가로 반환한다.

GitHub [전체 재현 검사](https://github.com/GnuDaSsa/seongnam-budget-mcp/actions/runs/42568912140)는 새 Linux 환경에서 스냅샷 1,008개 파일의 다운로드·해시 검증, 빌드, 테스트 30개를 통과했다. 실제 UI 검증과 이 자동 검사는 별개다. 사용자 대화 URL과 화면은 공개 레포에 포함하지 않는다.
