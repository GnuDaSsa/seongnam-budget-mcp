수집 현황

ChatGPT에서 근거를 찾아보세요.

이 사이트의 MCP는 공개자료를 검색하고 원문 페이지를 읽습니다. 연결된 ChatGPT가 그 근거로 답변합니다.

로그인 없이 공개 MCP 연결

MCP 클라이언트에서 아래 주소를 Streamable HTTP 서버로 추가하세요. 공개 자료 검색에 로그인이나 API 키가 필요하지 않습니다.

아래 /public-mcp는 인증 없는 공개 경로입니다. Sites 자동 플러그인의 /mcp 경로는 별도 플랫폼 인증을 사용합니다.

일반 ChatGPT에 연결

ChatGPT의 플러그인 메뉴에서 사용자 지정 MCP 서버 추가를 선택하고 위 주소를 넣으세요. 인증은 No authentication으로 설정합니다. 설치 후 대화에서 성남 예산 아카이브를 선택하세요.

예산 MCP가 검색과 원문 근거를 반환하면, 사용 중인 GPT가 답변합니다. 별도의 모델 API 키는 필요하지 않습니다. 추가 가능 여부는 ChatGPT 계정·워크스페이스 정책에 따릅니다.
